# 포트폴리오 초안

인자: `$ARGUMENTS`

`Docs/Portfolio/portfolio_template.md` 형식으로 `Docs/Portfolio/PF-XX_<영문 요약>.md`를 작성하거나 갱신한다. `XX`는 기존 문서의 다음 번호이다.

## 규칙

- "선택 이유"는 사용자 결정 기록(문서, 커밋, 사용자 발언)에서만 가져오고 출처를 표기한다. 근거가 없으면 지어내지 말고 `근거 없음 — 본인 작성 필요`로 남긴다.
- 에이전트가 추천하고 사용자가 그 방향을 승인한 결정은 에이전트의 판단 근거를 쓰고 `[에이전트 판단 · 사용자 승인: <날짜>]`로 표기한다.
- "배운 점"과 예상 질문의 답은 비워둔다. 사용자가 직접 작성한다.
- 상태는 `초안`으로 두고, 사용자가 검토한 뒤 `검토 완료`로 바꾼다.
