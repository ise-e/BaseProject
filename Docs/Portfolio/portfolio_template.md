# PF-XX · 제목

> 면접에서 30초 안에 설명할 수 있는 한두 문장 요약. 무엇을, 왜, 어떻게 해서, 어떤 결과를 얻었는지 담는다.

**유형:** 기능 구현 / 설계 결정 / 문제 해결

**상태:** 초안 (에이전트 작성) / 검토 완료 (본인 확인)

**관련:** 마일스톤 `M-XX`, 요구사항 `FR-000`, 상세 명세 `DS-XX-X`, 커밋 `<ID>:`

**작성 규칙:**

- 각 항목 끝에 출처를 표기한다.
    - `[사용자 결정: <문서·커밋·발언 날짜>]`: 사용자가 내린 판단
    - `[에이전트 판단 · 사용자 승인: <날짜>]`: 에이전트가 추천하고 사용자가 그 방향을 승인한 판단
    - `[기록: <문서·커밋·실행 기록>]`: 저장소에 남은 사실
    - `[에이전트 분석]`: 에이전트의 해석이나 정리 (승인받지 않은 의견)
- "선택 이유"는 사용자 결정 또는 사용자가 승인한 에이전트 판단으로만 채운다. 근거가 없으면 지어내지 말고 `근거 없음 — 본인 작성 필요`로 남긴다.
- "배운 점"과 "예상 질문의 답"은 본인이 작성한다. 에이전트는 비워둔다.
